### 👋 About me

I'm **Softbrick** — I build tools for the **NewbiesTeam** community: custom ROMs, kernels, recoveries and guides for the **Infinix GT 20 Pro (X6871)**, plus the apps and platforms around them. Part-time educator-tooling tinkerer (IGCSE exam analytics, tutor portfolios), full-time ship-it-yourself kind of dev.

### 🚀 Public projects

| Project | What it is | Stack |
|---|---|---|
| [newbiesteam-dev](https://github.com/zcyrl/newbiesteam-dev) | Internal developer portal + Android app to upload ROMs, guides, modules & changelogs | JavaScript, Android |
| [newbiesteam-desktop](https://github.com/zcyrl/newbiesteam-desktop) | NewbiesTeam desktop companions — GT 20 Pro Web Hub, self-contained builds | Kotlin, Compose Multiplatform, KCEF |
